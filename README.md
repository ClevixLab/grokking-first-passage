# First-Passage Prediction of Grokking Delay

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![arXiv](https://img.shields.io/badge/arXiv-pending-b31b1b.svg)](#)
[![audit](https://img.shields.io/badge/audit-16%20PASS%20%2F%200%20FAIL-brightgreen)](audit_report.txt)

This repository contains the code, data, and analysis scripts that reproduce every numerical claim, figure, and table in the paper:

> **First-Passage Prediction of Grokking Delay: A Calibrated Law under AdamW with Causal Validation**
> Truong Xuan Khanh, Truong Quynh Hoa, Luu Duc Trung, Phan Thanh Duc.
> Preprint, 2026.

The closed-form law fitted in this work,

$$T_{\mathrm{grok}} - T_{\mathrm{mem}} \;\approx\; \frac{1}{2\,\kappa_{\mathrm{LL}}\,\eta\,\lambda}\,\log\frac{V_{\mathrm{mem}}}{V_\star},$$

predicts AdamW grokking delays with MAPE 17.7% on 26 held-out runs spanning a 41× delay range, and is causally validated by representation-mixing interventions (Block F: 0/6 grok vs.\ 3/3 baseline).

## Quick verification (no GPU, < 30 seconds)

```bash
cd code
python audit_repo.py            # Expected: 16 PASS, 0 PARTIAL, 0 FAIL, 0 SKIP
```

The audit script verifies every paper claim against the shipped data with strict tolerances and explicit sample-size checks. The full report is written to [`audit_report.txt`](audit_report.txt).

> **Note:** `audit_repo.py` and the other analysis scripts use paths relative to the `code/` directory. Always run them from inside `code/`, e.g. `cd code && python audit_repo.py`.

## Reproduction tiers

The repository supports three tiers of reproduction depending on available compute:

### Tier 1 — Audit only (no GPU, < 30 sec)

Verifies every paper claim against shipped data:

```bash
cd code && python audit_repo.py
```

Recommended for fast review. Produces `16 PASS, 0 PARTIAL, 0 FAIL, 0 SKIP` confirming all numerical claims match.

### Tier 2 — Re-run analysis scripts (CPU only, ~10 minutes)

Regenerates everything in `results/` from `data/` and `raw_data/`:

```bash
cd code
python S16_regenerate_summaries.py         # Refresh data/ summaries from raw_data/
python explore_trajectories.py              # Per-trajectory kappa fits
python analyze_v3.py                        # Per-cell aggregation
python analyze_kappa_statistics.py          # Cross-arch kappa stats
python analyze_cross_cell_residuals.py      # V_star residuals
python predictive_validation.py             # Method A/B + LOOCV
python predictive_validation_three_tier.py  # Three-tier MAPE
python verify_refit_T_grok95.py             # Kosson refit + overshoot
python audit_repo.py                        # Verify regenerated results
```

### Tier 3 — Full retraining from scratch (~6.5 GPU-hours on RTX 4090)

Re-runs every experimental campaign:

```bash
cd code
python master_experiment_v8.py                      # Cross-arch sweep (~2h)
python master_experiment_v7.py                      # Block F causal (~0.5h)
python run_block_H_cross_cell.py                    # Block H 12-cell (~1h)
python run_modular_transformer2_validation_v2.py    # Paper-2L N=29 (~1.3h)
python run_modular_transformer2_alternative.py      # Alt-2L N=30 (~1.5h)
# Then run all Tier 2 analysis scripts
```

Hyperparameters and seeds are fixed; results should match within stochastic floor.

## Setup

```bash
bash setup_environment.sh    # Creates venv, installs from REQUIREMENTS.txt
source venv/bin/activate
```

Or manually:

```bash
python -m venv venv && source venv/bin/activate
pip install -r REQUIREMENTS.txt
```

Dependencies: PyTorch (CUDA optional for Tiers 1/2), NumPy, SciPy, Matplotlib (for figures only).

## Determinism

All training scripts use `seed_all()` from `code/shared_grokking.py`, which pins NumPy, PyTorch, and CUDA seeds and enables `torch.use_deterministic_algorithms(True)`.
